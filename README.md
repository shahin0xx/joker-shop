🎮 JOKERPLAYSTATION — A Beautiful, Powerful & Fully Dynamic Django Gaming Store
A professional, SEO-optimized Django e-commerce platform built for a PlayStation & gaming retail store — designed to be fully manageable without touching a single line of code.

✨ Highlights
🎨 Dynamic, Themeable Design
A beautiful and eye-catching UI with a live theme engine featuring 10 built-in color themes (Default, Ocean, Forest, Sunset, Midnight, Cyberpunk, Classic, Royal, Neon, Candy). Every color — header, navigation, dropdowns, buttons, footer, accents, loading animations, and cart badges — can be customized directly from the admin panel. No redeployment needed.

⚙️ Zero-Code Administration
Site settings, colors, contact info, social links, payment details, store address, referral rewards, and content (news, videos, sliders, "About Us") are all editable through a rich Django admin interface. The admin panel itself is protected by a hidden lock/unlock mechanism.

🔍 Professional SEO
Clean slug-based URLs, dynamic XML sitemaps for static pages, categories, games, products, news, and videos, plus proper metadata throughout — built to rank.

🛒 Complete E-Commerce Flow

Multi-step checkout (recipient info → discount code → payment receipt upload)

Card-to-card and SHABA payment methods with automatic threshold switching

Discount code system with percentage/fixed types and expiry dates

Referral system with automatic rewards (credit + discount codes) for both referrer and new user

Order tracking, receipts, and Telegram notifications for new orders

🕹️ Rich Game Catalog
Two game systems (GameList + the modern Game model), multi-image galleries, embedded video trailers (Aparat & YouTube), genre tagging, platform filtering, ratings, and featured/status flags.

💬 Real-Time Support Chat
Built-in AJAX-powered chat between customers and admins, supporting text, images, and video messages with read/unread tracking.

📦 Content Management
News, video library, homepage sliders, and an editable About Us page — all managed from the dashboard.
